# Urdu (ur): points for the medical translator to check

- **Gender:** Second-person lines use the respectful plural (آپ … رہے ہیں، آئے تھے), which is grammatically masculine but standard for any reader. Companion lines refer to the patient in the respectful plural (مریض جا رہے ہیں، ان کا سر درد).
- **First-person buttons:** Where possible these avoid gendered verbs: "مجھے جانا ہے" for "I'm leaving", "نہیں، ابھی نہیں جانا", and "مجھ سے یہ نہیں ہو سکتا". "I'm telling staff" still uses a slash: "بتا رہا/رہی ہوں". "مجھے جانا ہے" literally means "I need to go". Confirm that is acceptable.
- **"I'm not sure":** Rendered as "مجھے یقین سے معلوم نہیں" ("I don't know for certain"). Check that it isn't read as "no".
- **Triage nurse:** "ٹرائیج نرس آپ کے پاس آئیں گے" uses the masculine respectful plural so the nurse isn't assumed to be female. "آئیں گی" may sound more natural. "Triage" is kept as ٹرائیج, glossed once as (ابتدائی جانچ).
- **Seizure:** Rendered as "جھٹکوں والا دورہ (مرگی جیسا دورہ)". Check that it is clear and not stigmatizing. "Confusion" became "ذہنی الجھن (کنفیوژن)".
- **Check-in:** The repeated questionnaire became "سوالات" ("questions"), for example "اگلے سوالات" and "سوالات شروع کریں". Being registered became "اندراج". Check this is clear for low-literacy readers. "Sign in/out" stays as the English loanwords سائن اِن / سائن آؤٹ.
- **Vomiting:** Rendered as "اُلٹی (قے)". Shoulder blades became "پیٹھ پر دونوں کندھوں کے درمیان".
- **Triage card (`triageInfo`):** The heading keeps "ترجیحی سطح (ٹرائیج لیول)" from the privacy panel. The nurse sentence uses "ٹرائیج نرس کی طرف سے" to avoid a gendered verb. Level names: "انتہائی فوری / فوری / کم فوری / غیر فوری". No target times are shown on purpose; please keep it that way.

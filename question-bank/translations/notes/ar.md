# Arabic (ar): points for the medical translator to check

- **Avoiding gender:** Buttons use verbal nouns (بدء، إرسال، الإكمال لاحقًا) and instructions use يُرجى + verbal noun, so most lines don't mark gender. Where gender couldn't be avoided, the text uses the masculine default: "هل ستغادر؟", "لا، سأبقى", and المريض / companion verbs (يحتاج، تقيّأ، صداعه). The patient role button reads "أنا المريض / المريضة".
- **"I'm not sure":** This became "لا أعرف" ("I don't know"), because "لستُ متأكدًا" is gendered. Please confirm patients won't read it as "no" just because it starts with لا.
- **"Harder to stay awake" / drowsiness:** This became "مقاومة النوم" ("resisting sleep") so it isn't gendered. The option adds "(نعاس شديد)". Please check that it is as clear and urgent as "صعوبة في البقاء مستيقظًا".
- **Triage:** Rendered as "مكتب الفرز (الترياج)". "Triage nurse" became the collective "تمريض الفرز", which avoids picking ممرض or ممرضة. Check which term Calgary's Arabic speakers recognize.
- **"Seizure (fit)":** Rendered as "نوبة تشنّج (نوبة صرع)". Some readers link صرع with stigma or a chronic diagnosis, so check this.
- **"Worst headache of my life":** Rendered as "أسوأ صداع على الإطلاق" ("worst headache ever"). The same option list appears in companion mode, where "my life" would be wrong.
- **Clinician:** Rendered as "أحد أفراد الفريق الطبي" ("a member of the medical team"). Staff became "أحد أفراد الطاقم".
- **Check-in:** Being registered became "تسجيل الحضور". The repeated questionnaire became "أسئلة المتابعة". titleCompanion was reworded to "دورك: مساعدة المريض في الإجابة".
- **"Health number":** Rendered as "رقم بطاقتك الصحية" (Alberta health card number).
- **Triage card (`triageInfo`):** The heading reuses "مستوى أولويتك في الفرز" from the privacy panel. Level names: "عاجل جدًا / عاجل / أقل إلحاحًا / غير عاجل". "تمريض الفرز" stays collective to avoid gender. The level-3 line uses "من حالتهم أشد" (those in worse condition); check that it is clear. No target times are shown on purpose; please keep it that way.
